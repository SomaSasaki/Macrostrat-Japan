# Macrostrat Japan: 研究上の問いに対する学術回答台帳 (RESEARCH_QUESTIONS_LEDGER.md)

本台帳は、先行研究（CriticalMAAS, PaleoDeepDive, BGS, China KG, Italy, Belgium）との比較に基づき、プロジェクトが答えるべき 12 の研究上の問い（Q1〜Q12）に対する客観的回答を記録したものである。

---

## Q1. Macrostrat Japan のうち、既に研究として解決されている部分は何か？
- **回答**: 
  1. PDF/OCR からの地層名・岩相・地質年代エンティティ抽出（PaleoDeepDive, BGS）。
  2. 地質報告書からの層序関係（`overlies` 等）のテキスト抽出（China GeoERE-Net, BGS）。
  3. ESRI Shapefile の幾何・属性パース（標準 GIS 技術）。
  - これら単体技術は既に解決されており、自作・車輪の再発明の対象ではない。

## Q2. 今から自作せず流用した方がよい技術は何か？
- **回答**:
  1. **OCR / Layout Engine**: PyMuPDF / pdfminer / Tesseract（自作せず既存ライブラリをラップする）。
  2. **地質関係オントロジー語彙**: BGS および China D2 (2024) で定義された 24 種の標準関係定義。
  3. **国際層序標準対比表**: ICS 2023/09 スキーマ。

## Q3. Macrostrat Japan に現在不足している最重要機能は何か？
- **回答**: **定量的評価基盤（Gold Standard と Evaluation Suite）**。
  - 5〜10 図幅の専門家手動作成カラムを正解データとして固定し、AI 出力との一致率（Precision / Recall / F1、層序順序正解率）を自動集計するベンチマーク環境の構築が最優先課題である。

## Q4. 今すぐ architecture を変更すべきものは何か？
- **回答**: 
  - 抽出値のエビデンス保持形式において、単なる文字列だけでなく「説明書 PDF の該当ページ番号・原文引用」を構造化して記録する **Provenance スキーマの標準化**（既に一戸図幅で実証開始）。

## Q5. 今は変更せず、prototype 完成後に変更すべきものは何か？
- **回答**:
  - PostgreSQL / PostGIS への移行、Macrostrat 公式 API v3 Ingestion への接続、地球化学・鉱床データの統合。現在はスタンドアロンの軽量パイプラインで層序バックボーンを確立すべきである。

## Q6. Macrostrat Japan 独自の研究貢献になり得る部分はどこか？
- **回答**:
  - **「地質図の空間ポリゴン分布と説明書テキストを統合し、複数地域にまたがる層序柱状図（Column Region）を半自動導出して Macrostrat 互換データへ変換する、異種公的資料統合エンドツーエンドパイプラインの実装と実証」**。

## Q7. `column_map.py` は既存研究と比べて本当に独自なのか？
- **回答**: **独自性あり（学術的ギャップ）**。
  - Italy SHZ (2025) は「人間が手動で用意した層序位置」を空間展開するのみである。地質図内の排他的地層ポリゴン（Exclusive-unit）をシードとしてボロノイ分割し、柱状図フットプリントを自動導出するアルゴリズムは先行研究にない独自のアプローチである。

## Q8. PDF→relation→column という end-to-end pipeline の最も近い先行研究は何か？
- **回答**:
  - **PaleoDeepDive (2014)**（文献→DB抽出）と **Italy SHZ (2025)**（地質図→柱状図空間展開）の中間に位置する。完全に一体化したパイプラインとしては本研究が先駆的な位置を占める。

## Q9. Human–AI Loop の最も近い先行研究は何か？
- **回答**:
  - **ベルギー地質調査所 (Geological Survey of Belgium, EGU 2026)**。地質公理（Axioms）による自動検証を経て人間が不確実性をレビューする枠組みが最も近い。

## Q10. 未踏ITで「研究開発対象」とすべき未解決問題は何か？
- **回答**:
  - **「不均質で複雑な地質図幅・説明書 PDF から、地質学的整合性を担保しながら地域層序柱状図を自律合成・監査・可視化する統合ソフトウェア基盤の開発」**。

## Q11. 修士研究として定量評価できる scientific question は何か？
- **回答**:
  - **「LLMに基づく地質関係抽出と決定論的空間幾何演算のハイブリッド処理は、専門家による手動層序柱状図構築と比較して、どれだけの精度（F1・層序順序一致率）と時間削減効率（Review Time Reduction）を達成できるか？」**

## Q12. Japan から Korea・East Asia 等へ generalize するうえで技術的に何が必要か？
- **回答**:
  - 各国地質調査所の配布フォーマット（GIS スキーマ、凡例記述言語、報告書レイアウト）を吸収する **Document Adapter / GIS Schema Mapping Layer** の抽象化。
