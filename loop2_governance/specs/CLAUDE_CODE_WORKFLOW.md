# Claude Code 開発・連携ワークフロー

## 1. Claude Code の役割
Claude Code は、第1ループにおける **「重推論・長文PDF解析・Vision抽出・自律リファクタリング」** を担当します。

## 2. コマンドラインからの起動手順
ターミナル上で以下のように実行します：

```bash
# 例: 特定タスクの自律実行
claude "specs/TASK-001_example.md を読み込み、要件に従って scripts/llm_extract.py を改修し pytest を通してください"
```

## 3. 行動原則
- 変更前に必ず関連するテスト（`tests/`）を確認すること。
- 年代推論アルゴリズムを変更した場合は、過去のゴールデン図幅（`tests/` 配下の回帰テスト）でリグレッションが発生していないか確認すること。
